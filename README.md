# Networx Technologies — React + Vite + Tailwind UI

This is the UI-only React migration of the supplied PHP home page.

## Stack

- React
- Vite
- JSX
- Tailwind CSS
- Responsive/mobile-first UI

## Current scope

- Top Register / LogIn bar
- Responsive logo/navigation
- Services dropdown
- Home hero slider
- Networx Technologies intro
- Three service boxes
- Client-first parallax section
- Footer/social links

Backend/API/database/authentication are intentionally not implemented yet.

## Run

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```
